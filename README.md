Skript pro pridani exif pres sendto menu

Pouziti: 
vybrat fotky, prava mys > odeslat> exif, v okne vyplnit klicovat slova/tagy. 
Oddelena carkou nebo strednikem, do souboru se pridava strednik
Zpracovavaji se 4 najednou
Okno se po dokonce bez dalsiho zavre. 

Nutne nainstalovat exiftools, musi byt v %path%

Instalce
ulozit exif.ps1 i exif.cmd 
win+r > spustit > shell:sendto
v otevrenem adresari udelat zastupce exif.cmd
upravit v exif.cmd cestu k exif.ps1 (xxxx)
